### やったこと

`app/ask.py` に `--chat` を追加し、同じ会話の中で続けて質問できるようにした。

1. `client.chats.create(model=MODEL)` でチャットを1つ作る。
2. 入力を受け取り、同じチャットの `send_message()` を繰り返し呼ぶ。
3. SDKが過去のユーザーの質問とモデルの回答を次のリクエストに含める。
4. 回答のたびに入力・出力トークン数を表示する。

`/reset` で新しいチャットを作って履歴を消去し、`/exit`・EOF・Ctrl+Cで終了できる。空入力はAPIへ送らない。APIエラー時は自動再試行せず、利用者が再入力または終了できるようにした。履歴は実行中のメモリだけに保持し、ファイルへ保存しない。

既存の単発質問と、質問省略時の既定質問も維持した。

```bash
# 従来の単発質問
uv run python -m app.ask "LoRAとは何ですか？"

# 会話履歴を保持する対話
uv run python -m app.ask --chat

# 最初の質問を指定して対話を始める
uv run python -m app.ask --chat "私の名前はこうきです。覚えておいてください。"
```

### 気づき・疑問（実装から分かったこと）

- 会話を継続するには、毎回新しいチャットを作るのではなく、同じチャットを再利用する必要がある。
- 履歴はモデルの重みへの学習ではなく、次のリクエストに渡す情報である。プログラムの終了・再起動後には引き継がれない。
- 履歴を送るため、会話が長くなると入力トークンが増える可能性がある。今回の実装では自動要約や長さ制限は行っていない。増加量は実APIで確認したい。
- 履歴に誤った回答が含まれることもあり、会話を覚えていることと回答が正しいことは別である。
